# 📈 Progressive Web Application for Share Market Analysis with Live Chat

A **Progressive Web Application (PWA)** designed for **share market analysis** with stock-wise dashboards and a **live chat interface**.  
The application provides insights into selected stocks and supports **Android deployment** using Buildozer.

---

## 🚀 Features

- 📊 Share market analysis for multiple companies
- 🏦 Stock-wise dashboards (Axis, HDFC, ICICI, Tata, Reliance)
- 💬 Live chat interface for user interaction
- 📱 Progressive Web Application (PWA)
- 🤖 Android application support using Buildozer
- 🧮 Data analysis using NumPy
- ⚡ Fast, responsive, and user-friendly UI

---

**Frontend**

**Backend**
